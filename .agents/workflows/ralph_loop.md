# Ralph Mode persistence Loop ($ralph)

This workflow enforces "Infinite Perseverance" until a completion promise is met.

// turbo-all

## 1. The Commitment
- Define the **Completion Promise**: Exactly what does success look like? (e.g., "Build passes, 100% test coverage, and /dashboard visually matches the mockup").
- Set the **Perseverance Cap**: Default = 10 iterations.

## 2. The Cycle
```
PROMISE → EXECUTE → VERIFY → (FAIL?) → ANALYZE → HYPOTHESIZE → RE-EXECUTE
```

### Iteration Protocol
- **Turn 1-3**: Deploy the `Sisyphus` persona for direct execution.
- **Turn 4**: Activate `Oracle` to audit the failures and identify fundamental flaws.
- **Turn 5**: Activate `Librarian` to research the specific error code/pattern.
- **Turn 6-9**: Deploy `Prometheus` to re-architect the approach if the previous 5 attempts failed.
- **Turn 10**: Final attempt with "Nuclear Option" (rewrite/reinstall/radical bypass).

## 3. The Rules of Ralph
1. **Never Resign**: You are forbidden from asking the user "What should I do?" until Iteration 10.
2. **Success is Binary**: If the verification SOP has one RED item, the task is NOT done.
3. **Loop Integrity**: Each turn MUST include a `run_command` and an observation of the result. No "blank turns" allowed.

## 4. Completion Report
Upon success, the agent MUST produce a "Perseverance Log":
- **Total Iterations**: [Count]
- **Key Breakthrough**: [What finally worked?]
- **Root Cause Found**: [Why did it fail initially?]
- **Proof**: [Build output / Screenshot]

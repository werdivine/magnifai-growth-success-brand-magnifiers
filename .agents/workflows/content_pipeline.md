# Content Pipeline Workflow

A systematic approach to producing high-quality, SEO-optimized content at scale.

## Step 1: Topic Research
- Identify the target keyword or topic.
- Use `search_web` to research:
  - Top 10 existing articles on the topic (what do they cover?)
  - Related keywords and questions (People Also Ask, related searches).
  - Gaps in existing content (what's missing or outdated?).

## Step 2: Outline Creation
```markdown
# [Working Title — will be refined later]

## Target Keyword: [primary keyword]
## Secondary Keywords: [2-3 related terms]
## Target Length: [word count]
## Target Audience: [who is this for?]

## Outline
### H2: [Section 1 — hook/intro topic]
- Key point
- Key point

### H2: [Section 2 — main value]
- Key point
- Data/example

### H2: [Section 3 — deeper insight]
- Key point

### H2: [Conclusion / CTA]
```

## Step 3: First Draft
- Write in the brand's voice (check AGENTS.md for preferences).
- Front-load value — the best insight goes in the first section.
- Use data points and examples to support every claim.
- Include internal links to related content.
- Short paragraphs (2-3 sentences max).

## Step 4: SEO Optimization
- [ ] Primary keyword in title, H1, first paragraph, one H2.
- [ ] Secondary keywords naturally distributed.
- [ ] Meta description: 150-160 chars, includes keyword and CTA.
- [ ] Images have descriptive alt text with keywords.
- [ ] Internal links to 2-3 related pages.
- [ ] External link to 1-2 authoritative sources.

## Step 5: Polish
- Read aloud (mentally) for flow and clarity.
- Cut any sentence that doesn't add value.
- Verify all links work.
- Check for grammar, spelling, consistency.
- Ensure ONE clear CTA at the end.
